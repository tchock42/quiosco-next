Esta es una aplicación de NEXT.JS llamada Quiosco de Comida y se desarrolla usando App Router (carpetas anidadas donde cada carpeta es un nivel en la url) y Prisma como ORM
Se usa la configuración Server Components con la carpeta app sirviendo como router.

## Tecnologías usadas

- React
- Typescript
- Fetch API
- API para la obtención de JSON de la base de datos
- Prisma
- PostgreSQL

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
